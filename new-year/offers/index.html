Правило sweepstakes

Покупка не влияет на результат ивента. Ни одна покупка не даёт ракет, печатей, билетов, сегментов или очков и не повышает шанс на приз. Ивенты проходятся бесплатно (No purchase necessary). Офферы идут в ответ на участие, а не вместо него. Иначе розыгрыши и конкурсы становятся платными, и это юридический риск для всех брендов.

Награды ивентов: бонус + оффер

Каждый уровень награды состоит из двух частей. Бесплатную часть оставляем, но делаем меньше. Деньги в ней экономим, а ценность для игрока держим через усиленный персональный оффер.

Бонус · бесплатно

Промокод, как сейчас

GC / SC / FP (у FWL — FC). Выдаётся автоматически через Claim prize, его получает любой участник уровня. Это и есть приз ивента, без него нет «No purchase necessary».

Оффер · персональный

Пакет с усиленным бонусом

Открывается только этому игроку, лимит 1, живёт 48–72 часа. Бонус выше обычной сетки (+40… +100% против привычных +20%). Тематическое название из мира бренда. Брать его не обязательно.

Как это сделать технически — главный открытый вопрос. В админке оффер = доступность → пакет (+ FP). Для персональных офферов нужна доступность, видимая только списку player ID из export ивента. Если так нельзя, запасной путь: оффер открывается по промокоду, который бот выдаёт вместе с бонусом. Нужно проверить в админке до начала разработки.
